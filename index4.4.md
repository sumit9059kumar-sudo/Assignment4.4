Part 1: The Metadata Code Snippet
<!-- 1. Character Encoding -->
    <meta charset="UTF-8">

    <!-- 2. Mobile Viewport Meta Tag -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- 3. Meaningful Page Title -->
    <title>Alex Morgan | Web Developer Portfolio & Blog</title>

    <!-- 4. Meta Description for SEO -->
    <meta name="description" content="Explore the personal portfolio and web development blog of Alex Morgan, featuring semantic HTML projects and coding guides.">

    <!-- 5. Favicon -->
    <link rel="icon" type="image/x-icon" href="images/favicon.ico">

    <!-- 6. Verified CSS Stylesheet Link -->
    <link rel="stylesheet" href="style.css">
    Part 2: Full Updated HTML File Example
    <!DOCTYPE html>
<html lang="en">
<head>
    <!-- Metadata & Page Setup -->
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Alex Morgan | Web Developer Portfolio</title>
    <meta name="description" content="Personal portfolio and project showcase for Alex Morgan, an aspiring front-end web developer.">
    
    <!-- Favicon link (make sure favicon.ico is inside your images folder) -->
    <link rel="icon" type="image/x-icon" href="images/favicon.ico">
    
    <!-- CSS stylesheet link with verified path -->
    <link rel="stylesheet" href="style.css">
    
    <style>
        body { font-family: Arial, sans-serif; margin: 40px; text-align: center; color: #333; }
        h1 { color: #2c3e50; }
        p { color: #555; }
    </style>
</head>
<body>

    <header>
        <h1>Welcome to My Updated Website</h1>
        <p>This page now includes full metadata, character encoding, and a browser favicon!</p>
    </header>

    <main>
        <p>Check your browser tab to see the custom title and favicon in action.</p>
    </main>

</body>
</html>
Requirements Checklist for Submission:
Character Encoding: Included <meta charset="UTF-8"> in every HTML file.

Viewport: Added <meta name="viewport" content="width=device-width, initial-scale=1.0"> for responsive mobile scaling.

Title: Written a descriptive and unique <title> for each page.

Meta Description: Added a summary <meta name="description" content="..."> tag for search visibility.

Favicon: Added a <link rel="icon" ...> tag and placed a favicon.ico file in your project folder.

File Paths: Verified that CSS links and image/favicon paths match your folder structure.
